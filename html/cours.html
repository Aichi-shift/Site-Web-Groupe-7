CSS : mise en forme du texte

Cours développé • tailles, polices, styles, alignement et couleurs

Cette fiche reprend les notions essentielles du cours et les accompagne de définitions, d’exemples corrigés et de bonnes pratiques. Les règles CSS s’appliquent aux éléments HTML grâce aux sélecteurs.

RAPPEL : STRUCTURE D’UNE RÈGLE CSS

sélecteur {
    propriété: valeur;
}
VI

VI — Taille des caractères

1. Définition et unités de taille

La propriété font-size règle la taille de la police. On distingue les longueurs dites absolues (une valeur explicite en px, pt, cm…) et les tailles relatives, qui dépendent d’une taille de référence. La syntaxe correcte est « font-size: valeur; ».

2. Tailles absolues

UnitéSignification et emploi
pxPixel CSS : courant pour les interfaces ; ce n’est pas forcément un pixel physique de l’écran.
pt / pcPoint (1 pt = 1/72 in) ; pica (1 pc = 12 pt). Surtout utilisés pour l’impression.
in / cm / mmPouce, centimètre et millimètre ; 1 in = 2,54 cm et vaut 96 px en CSS.

EXEMPLE : PARAGRAPHE DE 16 PX

p {
    font-size: 16px;
}
Attention Écrire « 16px » sans espace entre le nombre et l’unité. « rem » n’est pas une unité absolue : elle est relative à la taille de la police de l’élément racine.

3. Tailles relatives

Les unités relatives facilitent l’adaptation du texte aux réglages du navigateur et à la structure de la page. Elles sont généralement préférables pour une interface souple et accessible.

ValeurComment elle est calculée
emRelative à la taille de police héritée du parent : si le parent est à 20px, 1.5em donne 30px.
remRelative à la taille de police de l’élément racine (<html>) : si elle est à 16px, 1.5rem donne 24px.
%Pour font-size, pourcentage calculé d’après la taille héritée du parent.
Mots-clésxx-small, x-small, small, medium, large, x-large, xx-large : échelle de tailles définie par le navigateur.

Exercice corrigé : trois titres

Consigne : afficher « Année 2026 » en vert (1.5em), « Vontovorona » en bleu (1em) et « Antananarivo » en rouge (1.5em).

HTML

<body>
    <h1>Année 2026</h1>
    <h2>Vontovorona</h2>
    <h3>Antananarivo</h3>
</body>

CSS

h1 { color: green; font-size: 1.5em; }
h2 { color: blue;  font-size: 1em; }
h3 { color: red;   font-size: 1.5em; }
VII

VII — Police des caractères

1. Choisir une police avec font-family

La propriété font-family indique la ou les polices utilisées. Le navigateur essaie la première ; si elle manque, il passe à la suivante. Terminer de préférence la liste par une famille générique.

EXEMPLE

p {
    font-family: Impact, Verdana, sans-serif;
}
div {
    font-family: Georgia, "Times New Roman", serif;
    font-size: x-large;
}

Arial, Verdana, Georgia et Times New Roman sont des noms de polices. En revanche, serif, sans-serif, monospace et cursive sont des familles génériques. Mettre entre guillemets les noms qui contiennent des espaces.

2. Utiliser une police enregistrée dans le projet

On télécharge les fichiers autorisés, on les place dans un dossier du site, puis on les déclare avec @font-face. La licence doit être vérifiée : une police téléchargeable n’est pas nécessairement libre pour tous les usages (ex. Font Squirrel ou DaFont).

FormatÀ savoir
.woff2Format Web moderne, compressé et généralement à privilégier.
.woffFormat Web très répandu ; bonne solution de repli.
.ttf / .otfFichiers TrueType / OpenType, également utilisables sur le Web.
.eot / .svgFormats historiques ; principalement associés à d’anciens navigateurs.

ARBORESCENCE DU PROJET

mon_site/
├── index.html
├── styles/
│   └── style.css
└── polices/
    └── ballpark.woff

DANS STYLES/STYLE.CSS

@font-face {
    font-family: "Ballpark";
    src: url("../polices/ballpark.woff") format("woff");
    font-display: swap;
}

Le chemin ../polices/ remonte depuis styles/ vers la racine du projet puis entre dans le dossier polices/. Le nom du fichier doit correspondre exactement à celui téléchargé.

3. Charger une police depuis Google Fonts

Google Fonts permet d’intégrer une police hébergée en ligne. Dans le <head> du document HTML, ajouter le lien correspondant à la police choisie, puis utiliser son nom dans font-family. Une connexion Internet est nécessaire pour charger cette version distante.

À PLACER DANS <HEAD>

<link rel="stylesheet"
      href="https://fonts.googleapis.com/css2?family=Lavishly+Yours&amp;display=swap">

CSS POUR AFFICHER « BIENVENUE »

p {
    font-family: "Lavishly Yours", Arial, sans-serif;
    font-size: xx-large;
    color: blue;
}

Autre possibilité : télécharger le fichier de la police, par exemple LavishlyYours-Regular.ttf, puis le charger localement avec @font-face, comme pour Ballpark.

4. Exemple complet : Ballpark et Lavishly Yours

Résultat attendu : « Année 2026 » en Ballpark, bleu et x-large ; « Vontovorona » en Lavishly Yours, rouge et medium. Le premier fichier est local ; le second est chargé depuis Google Fonts.

INDEX.HTML

<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="utf-8">
    <title>Choix des polices</title>
    <link rel="stylesheet"
          href="https://fonts.googleapis.com/css2?family=Lavishly+Yours&amp;display=swap">
    <link rel="stylesheet" href="styles/style.css">
</head>
<body>
    <h1>Année 2026</h1>
    <h2>Vontovorona</h2>
</body>
</html>

STYLES/STYLE.CSS

@font-face {
    font-family: "Ballpark";
    src: url("../polices/ballpark.woff") format("woff");
    font-display: swap;
}
h1 { font-family: "Ballpark", Arial, sans-serif;
     font-size: x-large; color: blue; }
h2 { font-family: "Lavishly Yours", Impact, sans-serif;
     font-size: medium; color: red; }
VIII

VIII — Texte en italique

La propriété font-style contrôle l’inclinaison : normal affiche le style droit, italic utilise si possible la vraie variante italique de la police et oblique incline les caractères. Certaines polices ne proposent pas toutes les variantes.

CSS : ANNÉE 2026, VONTOVORONA ET UN PARAGRAPHE NORMAL

h1 { font-style: italic;  font-size: medium; color: blue; }
h2 { font-style: oblique; font-size: large;  color: red; }
p  { font-style: normal; }

HTML

<h1>Année 2026</h1>
<h2>Vontovorona</h2>
<p>J’aime cette école.</p>

IX — Texte en gras

La propriété font-weight règle l’épaisseur des caractères. normal correspond en général à 400 et bold à 700. On peut aussi utiliser lighter ou bolder, qui choisissent une graisse relativement à celle du parent.

ValeurGraisse approximativeValeurGraisse approximative
100Très fin200Extra-fin
300Fin400Normal
500Moyen600Semi-gras
700Gras800Très gras
900Très épais——

EXEMPLE

h1 { font-weight: 700; }
.mot-important { font-weight: bolder; }
À retenir Le rendu dépend des graisses réellement disponibles dans la police. En HTML, <strong> indique une importance sémantique ; le CSS règle l’apparence visuelle.
X

X — Décoration d’un texte

text-decoration ajoute une ligne au texte : underline (en dessous), line-through (au milieu) ou overline (au-dessus). La valeur none retire la décoration. Les éléments <span> permettent de cibler seulement quelques mots.

CSS

.soulignement { text-decoration: underline; }
.barre        { text-decoration: line-through; }
.au_dessus    { text-decoration: overline; }

HTML

<p>
  <span class="soulignement">Ce texte est souligné</span> d’abord,
  puis il est <span class="barre">barré</span>. Enfin,
  il est <span class="au_dessus">surmonté d’une ligne</span>.
</p>

Conseil : éviter de supprimer systématiquement le soulignement des liens ; leur aspect doit rester identifiable pour l’utilisateur.

XI

XI — Alignement d’un texte

La propriété text-align agit sur le contenu en ligne à l’intérieur d’un bloc, par exemple le texte d’un paragraphe ou d’un titre.

ValeurRésultat
leftÀ gauche
rightÀ droite
centerAu centre
justifyAlignement sur les deux bords ; espaces ajustés entre les mots

CSS

.titre {
    text-align: center;
    color: green;
    font-size: large;
}
.contenu {
    text-align: justify;
    font-size: medium;
}

HTML

<p class="titre">Découvrir le CSS</p>
<p class="contenu">Le CSS permet de présenter clairement les
textes, de choisir leurs couleurs et de structurer une page.</p>

Pour un court titre, centrer peut être utile. Pour de longues lignes, justify peut créer des blancs irréguliers : vérifier le résultat à l’écran.

XII

XII — Couleur du texte et de l’arrière-plan

1. Deux propriétés et plusieurs écritures

color définit la couleur du texte ; background-color définit celle du fond. Une même couleur peut s’écrire avec un nom anglais, un code hexadécimal, des composantes RGB(A) ou le modèle HSL(A). Un outil pipette, par exemple dans Paint, permet de relever un code sur une image.

ÉcritureExemplePrincipe
Nomcolor: red;Nom anglais d’une couleur prédéfinie.
Hexadécimalcolor: #25A958;Rouge, vert et bleu : deux chiffres hexadécimaux par composante.
Hex courtcolor: #0F8;Trois chiffres ; #0F8 équivaut à #00FF88.
RGBcolor: rgb(37, 169, 88);Chaque composante rouge, verte ou bleue vaut de 0 à 255.
RGBAcolor: rgba(37, 169, 88, 0.5);Le dernier nombre est l’opacité : 0 transparent, 1 opaque.
HSLcolor: hsl(145, 64%, 40%);Teinte en degrés, saturation en %, luminosité en %.
HSLAcolor: hsla(145, 64%, 40%, 0.5);HSL avec un canal d’opacité supplémentaire.
Correction rgb(44, 25, 347) est invalide comme notation entière : une composante RGB ne dépasse pas 255. On peut écrire par exemple rgb(44, 25, 255).

2. Comprendre la teinte HSL

Sur le cercle chromatique : 0°/360° = rouge, 60° = jaune, 120° = vert, 180° = cyan, 240° = bleu et 300° = magenta. La saturation mesure l’intensité de la couleur ; la luminosité indique si elle est claire ou sombre. Ainsi, hsl(240, 100%, 25%) donne un bleu foncé.

3. Exemple d’application

CSS

.carte {
    color: #183D29;
    background-color: #EAF7EE;
    font-family: Arial, sans-serif;
    font-size: 1.25rem;
    font-weight: 700;
    text-align: center;
}

HTML

<p class="carte">Bienvenue à Vontovorona</p>

Veiller au contraste entre le texte et le fond : un texte clair sur un fond très clair devient difficile à lire.
